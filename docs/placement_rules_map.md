# TAF 标准项 × 智能布点规则 一对多映射 (草案)

> 原则: 每个标准项可选的布点规则不同 —— 由该标准项的空间语义决定。
> 布局策略空间锚点 (DXF TAF 图层):
>   B=建筑(building) C=通道/走廊(channel) N=节点/广场(node)
>   G=绿地(green) F=沿街立面(facade) R=道路(road) Y=红线内(boundary)

## 规则实现 (前端引擎)
每条规则 = 锚点组合 + 布局算法 + 默认参数:
- 沿通道线性: anchors=C, 间距按项 (如照明18m/饮水100m), 单/双侧
- 节点辐射: anchors=N, 每节点1-2
- 红线入口: anchors=Y 近道路侧分段
- 绿地: anchors=G 内均匀
- 均匀: 全域网格
- 跟随 P1-02: 复用 P1-02 的 placements 坐标
每项数量: 按该项"单锚点数量×锚点数"且总长/间距推导 (弹性: 锚点不足时自动减少, 绝不0点卡死)
