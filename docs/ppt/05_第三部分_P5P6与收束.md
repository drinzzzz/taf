## P68 P6-03 在地文脉特色的宠物友好元素（叙述页）

**标准要求**（加分项）：将石库门元素融入宠物友好设计（如弄堂门牌风格）（评分原文；标准项全名见标题）——此项全名"在地文脉特色的宠物友好元素"，涵盖但不限于石库门语汇：从里弄门楣、清水砖墙、铸铁门窗中提取符号，转化为当代宠物设施语言。

**本案设计**：
- 视觉体系：饮水台/拾便箱/导览牌采用"石库门门牌 + 清水砖/铸铁"母题（样式示意见第四部分）；字号与图文规范沿用街区导览系统；
- 点位：设 **1 处**示范性在地文脉元素点位（主入口侧，与导览总览共构）；
- 全系设施（18 点位层）样式统一为该视觉体系，保证"风貌协调"整体达标（P6-01 联动）。

## P70 P6-01/02/04 合并叙述 + P6 小结

**P6-01 设施风貌协调性**（前置，风貌评审）：全部点位样式统一走"里弄语汇"视觉规范；设施体量克制（饮水台/标识柱 ≤ 常规家具尺度），色彩取砖红/铸铁黑/木色，避免高饱和色块；评审前提供全点位效果合成（以图系底图叠加符号）报风貌评审。

**P6-02 建筑结构保护**（前置）：实施原则——**不动结构、免打孔免嵌入**：设施以独立基座/花箱压重、抱箍式安装为主；贴墙件一律采用可逆固定（无痕胶垫/夹具），墙面不得开洞；施工交底与验收含结构检查项。

**P6-04 里弄空间适应性利用**（加分）：窄巷段设置贴墙折叠拴宠环（不占通行宽度）；天井/半私密空间适度布置丰容与休憩角（与商户/居民协商共建），让"边角空间"成为宠物友好节点而非死角。

**P6 小结**：P6-01/02 为实施铁律（本期设计已内化）；P6-03 点位落地 + 全系视觉；P6-04 边角利用方案随招商共建实施。
