## P04 项目背景（上）：区位与主体

**一条有底子的街区。** 兴顺里与兴顺东里位于上海徐汇区衡复历史文化风貌保护区、永嘉路沿线，由徐房集团所属上海衡复投资发展有限公司运营。项目总建筑面积约 6200㎡，涵盖品质公寓与特色商业，业态互补，形成片区级商业格局。兴顺东里已于 2025 年底正式亮相，秉持"保护性修缮"与"在地性活化"理念，在延续海派街巷肌理的同时融入当代生活需求——本项目的空间语言即建立在这套"风貌 + 生活"的语法之上。

**一个现成的友好锚点。** 项目地处永嘉路核心地段，与已建成并获 2021 年亚洲建筑师协会"社会与文化"建筑类金奖第一名和"社会责任奖"特别奖的嘉澜庭口袋公园（永嘉路 309 号）隔路相对。嘉澜庭实行宠物友好政策，是衡复风貌区内知名的社区社交地与宠物活动空间——它既是本项目"人宠友好"叙事的天然背书，也是未来培训、活动联动的外部场地资源。

**一段可预期的邻里氛围。** 衡复风貌区正推进商业焕新，聚焦打造武康路-安福路、衡山路-东平路、襄阳南路-永嘉路等商业集聚区；兴顺里处于襄阳南路-永嘉路邻里休闲街区辐射范围内，具备承接区域消费升级红利的条件。

## P05 项目背景（下）：政策与市场机遇

**市场体量已经够大、还在增长。** 据派读宠物行业大数据平台《2026 年中国宠物行业白皮书（消费报告）》：2025 年城镇宠物（犬猫）消费市场规模达 3126 亿元，同比增长 4.1%；城镇犬猫数量达 1.26 亿只；预计 2028 年市场规模达 4050 亿元。上海方面，据上海商业联合会与产业转型研究院的"上海宠物消费分布指数"，上海犬猫消费市场规模约 230–250 亿元，增速 10%–15%，占全国 7.8%–8.3%；90 后、00 后为主力，月收入 4000–15000 元群体贡献 60% 以上消费力——与永嘉路的客群画像高度重合。

**政策正在把"宠物友好"变成赛道与标准。** 徐汇区已将宠物经济纳入"国货潮品百品计划"重点赛道（聚焦食品饮料/健康美妆/箱包服饰/智能产品/潮玩文创/母婴宠物六大板块），对重点宠物企业给予落户奖励、鼓励首店旗舰店；2025 年 12 月天平街道牵头成立徐汇区首个宠物友好联盟，形成"政府引导、企业参与、行业自律"三方联动。上海市层面，国内首个宠物友好空间地方标准《宠物友好型商业场所及其室内场馆运行管理规范》已通过审定并正式报批——标准时代的到来，意味着"友好"将从口号变成可评估、可分级、可公示的指标。

## P06 策划目的：三层架构与本成果定位

项目的总体策划为**三层架构**：

- 第一层 · 硬件基础：人宠友好园区规划与配套设施（公共空间适宠化改造、宠物专属功能区、与嘉澜庭联动）

## P07 标准化的必要性：为什么要引入 TAF

"人宠友好"最怕两件事：一是做成口号——画几只宠物剪影就宣称友好；二是做成玄学——各家各做、好坏无法比较、验收没有依据。

因此本项目引入 **TAF（标准转化工具）**，其作用可用一句话概括：**把上游权威标准（中礼休协 T/CGLA 团标、上海市地方标准 DB31/T 1703-2026 等）翻译成一条条可执行的空间设计指令与评估条款**，再落到具体场地的图纸上。TAF 的价值在于提供：

1. **统一语言**：业主、设计、运营、商户说同一套标准编号（如 P1-02 饮水点 = 什么要求）；
2. **可核验**：每处点位对应明确评估条款与达标线，现场可查；
3. **可复制**：本册在兴顺里的做法，天然可作为后续街区/商业项目的方法样板。

本部分之后（第二部分）将完整介绍 TAF 体系，再（第三部分）以 TAF 逐条对照展开兴顺里方案。

## P10 TAF 是什么

**定位：标准的转化者，而非标准的制定者。**

TAF 本身不发明标准，它的职责是把上游权威标准转化为**可执行的空间设计工具与评估体系**：

- 上游（标准来源，三源并重）：
  1. 中礼休协 T/CGLA 团标（人宠友好相关评定团体标准）；
  2. 上海市地方标准 DB31/T 1703-2026《宠物友好型商业场所及其室内场馆运行管理规范》——国内首个宠物友好空间地方标准，本项目直接对标；
  3. 地方政府条例与既有行业导则。
- 下游（输出物）：
  1. 空间设计导则（8 大空间类型 × 6 个维度 × 5 级认证）；
  2. 布点与评估工具（本册所用：识别图层 → 语义分类 → 按规则布点 → 逐项评分）；
  3. 评估报告与达标等级。

一句话：**TAF 让"人宠友好"从价值观变成可交付的图纸与可核验的分数。**

## P11 评估体系总览（一）：六类框架

TAF OS 版（开放街区·商业场景）评估框架共六类，权重如下：

| 类 | 名称 | 权重 |
|---|---|---|
| P1 | 公共空间物理环境 | 0.20 |
| P2 | 商户参与与业态生态 | 0.18 |
| P3 | 运营管理与风险管控 | 0.15 |
| P4 | 动物福利、空间丰容与宠物体验 | 0.22 |
| P5 | 公共教育与社区共建 | 0.10 |
| P6 | 历史建筑适配性 | 0.15 |

解读要点（业主视角）：
- **P1**：空间物理底子——防滑、饮水、拾便、照明、导览等，决定"是否敢带宠物来"；
- **P2**：商户参与——"来了之后有没有宠物友好的消费场景"；
- **P3**：运营管理——制度与风险兜底（多为内部管理文件，本册第五部分呈现）；
- **P4**：动物福利与宠物体验（权重最高 0.22）——"宠物是否真的被善待、呆得舒服"，是体验口碑的来源；
- **P5**：公共教育——培训、认证、文明倡导，形成社区共建；
- **P6**：历史建筑适配——风貌街区特有的约束与机会。

## P12 评估体系总览（二）：35 项与计分逻辑

TAF OS 版共 **35 个标准项**，逐项给出：

1. **类型**：prerequisite（前置必达，如安全类）与 credit（加分项）；
2. **评分**：0–5 分档，各档有明确现场判定描述（如 P1-02 饮水点：≥3 处且低位=5 分 / 1–2 处=3 分 / 无=0 分）；
3. **评估方法**：多为"现场踏勘 + 照片佐证 + 人工校准"，部分涉及保洁记录核查、台账抽查；
4. **参考标准**：每项注明所依据的导则条文（如"每 200 米至少 1 处"类服务半径条款）。

其中 **18 项为可布点项**（能落到图纸上的点/区域），本册第三部分逐项展开；其余为制度、业态、运营类条款（叙述+管理文件支撑）。

## P13 开放街区·商业版导则要点（一）：与封闭商场的本质差异

兴顺里属于**开放街区型商业空间**（里弄街巷 + 沿街店铺），与封闭商场（单入口、可控人流）的友好设计逻辑不同，TAF 针对开放街区有专门条款设计，要点：

1. **边界不可控**：开放街区没有"关门"机制，宠物进入不设闸——友好必须靠**引导而非拦截**（导览、准入公示、动线提示）；
2. **红线即边界**：设施只能布置在红线内；红线外（马路、相邻地块）不可控，点位必须与红线保持安全距离（本册所有点位均已执行红线避让规则）；
3. **人宠动线交叉点增多**：街巷与店铺入口、车行与人行交汇处是冲突高发点——需要显性化标识（P1-04 动线冲突点标识 10 处）；
4. **与历史风貌共处**：设施不能损伤风貌立面与街巷肌理——点位与样式服从"在地文脉"约束（P6 类）。

## P14 开放街区·商业版导则要点（二）：点位密度与服务半径的逻辑

开放街区的设施密度不能拍脑袋，TAF 采用"导则条文 + 犬只行为学 + 商业可达性"三源推导，形成可复核的间隔阈值（1 图纸单位 = 1cm）：

| 设施 | 推导依据 | 阈值 | 兴顺里落位 |
|---|---|---|---|
| 公共饮水点 P1-02 | 标准条文 200m ≥1 处；犬 15–30 分钟补水需求；携宠步行 3–5 分钟可达 | 动线每 150m 1 处（至少 3 处） | 47m 主街按需推 3 处，实际 4 处（含节点） |
| 排泄物处理 P1-03 | 标准条文"每 50 米一组"；商业区实践 50–100m | 每 50m 一组 | 3 组（覆盖主通道与尽端） |
| 照明 P1-06 | 人行/商业街照度与庭院灯间距惯例 | 沿动线 25–30m 灯位 | 6 处（覆盖夜行安全） |

这套逻辑的意义：**密度可解释、可审计**——评审问"为什么这里放 4 个饮水点"，答案不是"感觉"，而是"按 150m 服务半径推导"。

## P15 TAF 落地流程：识别 → 布点 → 评估 → 迭代

一张图讲清 TAF 怎么把标准变成图纸：

1. **识别**：读底图 DXF，自动识别图层语义（红线/建筑/通道/节点/绿地/立面/建筑编号…）；
2. **分类**：每类空间赋予语义——建筑=室内禁区（点位布其外沿）、通道=可通行面、节点=广场开放区；
3. **布点**：按标准项调用布点规则（线性排布/贴墙带/服务半径/红线避让/节点避让），自动生成候选点位，人工复核微调；
4. **评估**：对照 35 项条款逐项计分（点位数量/位置/覆盖是否达标）；
5. **迭代**：不达标处回退调整——图纸与评估同源，改图即改分。

## P75 物料清单总表（二）：通用规格与材质要求

- **通用材质**：主体金属件 S304 不锈钢/耐候钢（哑光处理）；木质件防腐木/竹基复合；混凝土基座清水/砖色涂料；全部圆角无锐边。
- **耐候**：上海户外全季（-5~40℃），防水等级 IP54+，五金防锈；深色面材防烫（夏季日照下表面温度 ≤ 40℃，或设遮阳/隔热层）。
- **固定**：独立基座压重或抱箍可逆固定；**免打孔、免嵌入结构件**（P6-02 铁律）；每件配排水与检修口。

- **安全**：无夹爪缝隙（宠物部件缝隙 ≤ 5mm 或 ≥ 30mm 防卡爪）；无尖角外露；玩具/耗材类符合宠物安全材料标准（无毒、耐咬、可更换）。

## P76 重点一：P1-02/P4-01 低位宠物饮水点

- 规格：碗口离地 **15–20cm**（中小犬低头可饮，大犬亦舒适）；碗径 18–25cm、深 6–8cm，独立进水嘴（缓流），溢水口+排水接入地面排水；台体带拴宠环与置物位。
- 定制要求：低位碗状（P4-01 5 分档硬指标，非喷嘴式）；材质陶瓷/不锈钢防烫；冬季防冻（排水自净/加热选配）；每日清洁换水 ≥2 次（制度联动）。
- 提示：碗体弧度便于清洗无死角；颜色与砖墙语汇协调。

## P88 兴顺里人宠友好条约（正文一：总则与携宠守则）

**一、总则**
1.1 兴顺里为"人宠友好"开放街区：欢迎携宠到访，同时要求每一位主人对宠物行为、对他人感受、对街区环境负责。
1.2 本条约适用于街区公共区域；商户内部规则以各商户入口公示为准（见《商户宠物准入与管理规范》）。
1.3 街区管理方有权对违反本条约的行为进行劝导、记录，情节严重者按《应急预案》与相关规定处理。

**二、携宠基本守则**
2.1 **牵引**：进入街区公共区域，犬只须全程牵绳（绳长 ≤1.5m）；大型犬须同时佩戴嘴套（建议项）；烈性犬/禁养犬只按上海市相关规定不得入园。
2.2 **排泄**：请使用街区定点拾便设施（每 50m 一组）即时清理犬只排泄物，并利用"即时水冲"装置稀释处理尿液；不得放任犬只在绿化、树池、商户门口便溺。
2.3 **饮水**：请使用低位宠物饮水点；请勿让犬只直接饮用景观水体或他人食具。
2.4 **安静**：请控制犬只吠叫，尤其夜间（22:00 后）；在商户室内外避免长时间打扰他人。
2.5 **礼让**：遇老人、儿童、轮椅、其他犬只，主动收短牵引、靠边礼让；犬只间不友好时请即时带离。
2.6 **看护**：主人须始终在场看护，不得将犬只单独拴于公共区域无人看管；拴宠请使用专用拴宠环。

## P89 人宠友好条约（正文二：分区、商户、违约与附则）

**三、分区与准入**
3.1 公共空间（通道、节点、绿地）对全体牵引犬只开放；宠物社交角与游戏设施按时段/分区使用（见现场标识）。
3.2 商户空间：以各商户入口公示为准——"绿色"全友好、"黄色"限定区域（如宠物专属座位）、"红色"禁入（食品加工/卫生敏感类）。
3.3 商户公示状态实时更新于线上平台（P5-04），线上线下不一致时以现场公示为准并向管理方反馈。

**四、商户责任**
4.1 商户应按《商户准入与管理规范》完成公示、分区与员工培训；
4.2 友好商户应主动提供水碗/零食/等候位（P2-05）；非友好商户应在门口以友好措辞说明并引导至公共休息点。

**五、违约与处理**
5.1 轻微违规（未牵绳、未清理）→ 现场劝导 + 口头提醒；
5.2 重复违规 → 记录在案、书面提醒；造成他人损失或纠纷 → 按保险与《应急预案》流程处理；
5.3 严重或恶意违规（伤害他人/宠物、破坏设施）→ 列入不受欢迎名单，必要时报警。

**六、附则**
6.1 本条约自街区试运营日起试行，管理方保留修订权并提前公示；
6.2 解释权归街区运营方（上海衡复投资发展有限公司）及授权管理单位。

## P90 突发事件应急预案（正文一：总则与风险分级）

**一、总则**
1.1 目的：对街区内宠物相关突发事件快速响应、控制风险、规范善后，保障人宠安全与街区秩序。
1.2 适用范围：公共区域及商户联动场景。适用主体：街区管理方值班人员、商户员工、急救培训员。
1.3 原则：先控场、再处置、后记录；生命优先（人 > 犬 > 物）；不围观、不扩散。

**二、风险分级**
- **一级（普通，现场即处）**：犬只吠叫扰民、牵绳滑脱未伤人、地面排泄未清理、轻度口水/毛屑敏感投诉；
- **二级（关注，10 分钟内响应）**：犬只互咬（轻伤）、犬只惊吓儿童/老人（无伤）、宠物走失、呕吐/中暑初期；
- **三级（紧急，立即响应+必要时报警/120）**：犬只咬人（破皮出血）、人/宠重伤、烈性犬失控、火灾/触电类设施事故。

## P91 应急预案（正文二：响应流程与处置）

**三、响应流程**
3.1 发现/接报 → 值班人员到场（一级 5 分钟/二级 10 分钟/三级立即）；
3.2 控场：隔离犬只、疏散围观、安抚当事方；
3.3 处置（按分级）：
- 咬伤：人伤 → 清水冲洗 → 就医（狂犬疫苗建议）+ 犬只隔离观察 + 登记上报；宠伤 → 用 P4-04 急救箱初处置 → 送医；
- 中暑：移至阴凉 → 凉水降温（勿冰水直冲）→ 饮水 → 送医（急救箱冰袋初处置）；
- 走失：立即启用监控寻踪 + 线上平台发布 + 商户联动；
3.4 善后：事件记录（台账模板：时间/地点/当事方/经过/处置/保险）、回访、必要时修订规程。

**四、保险与记录**
4.1 街区为公众活动投保公众责任险（含宠物相关场景）；鼓励犬主投保第三者责任险（入园登记提示）；
4.2 每月汇总事件台账，季度复盘（对接 P3-03 投诉通道与 P3-05 保险条款）。

## P92 "狗狗好市民"三级奖牌体系 · 引子与框架（一）

**缘起**：本框架承接项目建议书第三层"公益培训与标准输出"，并呼应 TAF P3/P5 管理类条款——用"可认证的文明"替代"不可控的自觉"，让友好街区有清晰的行为入口。

**框架总览（铜 / 银 / 金三级）**

| 等级 | 能力要求 | 对应权益（空间准入闭环） |
|---|---|---|
| 🥉 铜牌·好市民 | 基础服从（召唤/坐下/待命）+ 公共场所行为规范考核（牵引、排泄、安静） | 可进入街区公共区域 |
| 🥈 银牌·好伙伴 | 完成社会化训练 + 人宠互动场景考核 | 可进入宠物友好商户室内 |
| 🥇 金牌·好邻居 | 高级行为训练 + 复杂环境适应性考核 | 可参与主题活动、享品牌合作权益 |

**与商户/空间联动闭环**：培训 → 认证 → 消费——铜牌进园、银牌进店、金牌享权益；商户凭银牌以上犬只可放心接待，管理方凭分级实现风险分层。
