## P10 TAF 是什么

**定位：标准的转化者，而非标准的制定者。**

TAF 本身不发明标准，它的职责是把上游权威标准转化为**可执行的空间设计工具与评估体系**：

- 上游（标准来源，三源并重）：
  1. 中礼休协 T/CGLA 团标（人宠友好相关评定团体标准）；
  2. 上海市地方标准 DB31/T 1703-2026《宠物友好型商业场所及其室内场馆运行管理规范》——国内首个宠物友好空间地方标准，本项目直接对标；
  3. 地方政府条例与既有行业导则。
- 下游（输出物）：
  1. 空间设计导则（8 大空间类型 × 6 个维度 × 5 级认证）；
  2. 布点与评估工具（本册所用：识别图层 → 语义分类 → 按规则布点 → 逐项评分）；
  3. 评估报告与达标等级。

一句话：**TAF 让"人宠友好"从价值观变成可交付的图纸与可核验的分数。**

## P11 评估体系总览（一）：六类框架

TAF OS 版（开放街区·商业场景）评估框架共六类，权重如下：

| 类 | 名称 | 权重 |
|---|---|---|
| P1 | 公共空间物理环境 | 0.20 |
| P2 | 商户参与与业态生态 | 0.18 |
| P3 | 运营管理与风险管控 | 0.15 |
| P4 | 动物福利、空间丰容与宠物体验 | 0.22 |
| P5 | 公共教育与社区共建 | 0.10 |
| P6 | 历史建筑适配性 | 0.15 |

解读要点（业主视角）：
- **P1**：空间物理底子——防滑、饮水、拾便、照明、导览等，决定"是否敢带宠物来"；
- **P2**：商户参与——"来了之后有没有宠物友好的消费场景"；
- **P3**：运营管理——制度与风险兜底（多为内部管理文件，本册第五部分呈现）；
- **P4**：动物福利与宠物体验（权重最高 0.22）——"宠物是否真的被善待、呆得舒服"，是体验口碑的来源；
- **P5**：公共教育——培训、认证、文明倡导，形成社区共建；
- **P6**：历史建筑适配——风貌街区特有的约束与机会。

配图建议：六类权重环形/条形图；每类一个小图标（可用 TAF 符号体系）。

## P12 评估体系总览（二）：35 项与计分逻辑

TAF OS 版共 **35 个标准项**，逐项给出：

1. **类型**：prerequisite（前置必达，如安全类）与 credit（加分项）；
2. **评分**：0–5 分档，各档有明确现场判定描述（如 P1-02 饮水点：≥3 处且低位=5 分 / 1–2 处=3 分 / 无=0 分）；
3. **评估方法**：多为"现场踏勘 + 照片佐证 + 人工校准"，部分涉及保洁记录核查、台账抽查；
4. **参考标准**：每项注明所依据的导则条文（如"每 200 米至少 1 处"类服务半径条款）。

其中 **18 项为可布点项**（能落到图纸上的点/区域），本册第三部分逐项展开；其余为制度、业态、运营类条款（叙述+管理文件支撑）。

配图建议：35 项总表（类/项/类型/可布点与否，一页可读）；计分示例条（0-3-5 档示意）。

## P13 开放街区·商业版导则要点（一）：与封闭商场的本质差异

兴顺里属于**开放街区型商业空间**（里弄街巷 + 沿街店铺），与封闭商场（单入口、可控人流）的友好设计逻辑不同，TAF 针对开放街区有专门条款设计，要点：

1. **边界不可控**：开放街区没有"关门"机制，宠物进入不设闸——友好必须靠**引导而非拦截**（导览、准入公示、动线提示）；
2. **红线即边界**：设施只能布置在红线内；红线外（马路、相邻地块）不可控，点位必须与红线保持安全距离（本册所有点位均已执行红线避让规则）；
3. **人宠动线交叉点增多**：街巷与店铺入口、车行与人行交汇处是冲突高发点——需要显性化标识（P1-04 动线冲突点标识 10 处）；
4. **与历史风貌共处**：设施不能损伤风貌立面与街巷肌理——点位与样式服从"在地文脉"约束（P6 类）。

## P14 开放街区·商业版导则要点（二）：点位密度与服务半径的逻辑

开放街区的设施密度不能拍脑袋，TAF 采用"导则条文 + 犬只行为学 + 商业可达性"三源推导，形成可复核的间隔阈值（1 图纸单位 = 1cm）：

| 设施 | 推导依据 | 阈值 | 兴顺里落位 |
|---|---|---|---|
| 公共饮水点 P1-02 | 标准条文 200m ≥1 处；犬 15–30 分钟补水需求；携宠步行 3–5 分钟可达 | 动线每 150m 1 处（至少 3 处） | 47m 主街按需推 3 处，实际 4 处（含节点） |
| 排泄物处理 P1-03 | 标准条文"每 50 米一组"；商业区实践 50–100m | 每 50m 一组 | 3 组（覆盖主通道与尽端） |
| 照明 P1-06 | 人行/商业街照度与庭院灯间距惯例 | 沿动线 25–30m 灯位 | 6 处（覆盖夜行安全） |

这套逻辑的意义：**密度可解释、可审计**——评审问"为什么这里放 4 个饮水点"，答案不是"感觉"，而是"按 150m 服务半径推导"。

## P15 TAF 落地流程：识别 → 布点 → 评估 → 迭代

一张图讲清 TAF 怎么把标准变成图纸：

1. **识别**：读底图 DXF，自动识别图层语义（红线/建筑/通道/节点/绿地/立面/建筑编号…）；
2. **分类**：每类空间赋予语义——建筑=室内禁区（点位布其外沿）、通道=可通行面、节点=广场开放区；
3. **布点**：按标准项调用布点规则（线性排布/贴墙带/服务半径/红线避让/节点避让），自动生成候选点位，人工复核微调；
4. **评估**：对照 35 项条款逐项计分（点位数量/位置/覆盖是否达标）；
5. **迭代**：不达标处回退调整——图纸与评估同源，改图即改分。

配图建议：流程示意图（五步横向箭头）；可放一张底图语义识别前后对比。
