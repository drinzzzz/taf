## 五、跨文件安全问题汇总

### 5.1 认证模型分析

**当前实现**:
- Token 基于数据库会话 (`auth_tokens` 表)
- 支持 Cookie/Bearer/Query 三种传递方式
- 会话有效期由 `session_days` 配置控制

**问题**:
1. Token 无刷新机制，过期需重新登录
2. 无设备/IP 绑定
3. 无并发会话限制
4. 登出时 Token 未标记为已使用 (`is_used` 字段存在但未使用)

### 5.2 多租户实现分析

**当前实现**:
- 每租户独立数据库 (`pm_<slug>`)
- 通过 `tenant_db.py` 动态路由
- 租户信息存储在 `platform_meta.tenants`

**问题**:
1. 租户 API (`tenant_api.py`) 未验证访问权限
2. 订阅 API (`subscription_api.py`) 可越权操作任意租户
3. 租户数据库名缓存可能不一致
4. 租户枚举风险（可获取所有租户列表）

### 5.3 配置管理分析

**当前实现**:
- 使用 `.env` 文件 + `dotenv` 加载
- 部分配置有默认值
- Feature flags 控制模块开关

**问题**:
1. 敏感配置默认值不安全
2. 无配置加密
3. 无配置变更审计
4. 无配置版本管理
