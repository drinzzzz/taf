  4. systemctl start mysql-tunnel
  5. 验证仅1个SSH进程

  步骤:
  1. 修改bookbaker.service，设置Type=simple
  2. ExecStart指向正确的uvicorn命令
  3. 停止nohup进程
  4. systemctl enable --now bookbaker

优先级 4: Hermes API Server纳入systemd管理
  步骤:
  1. 创建/etc/systemd/system/hermes-api.service
  2. 配置WorkingDirectory, ExecStart, User
  3. 添加Restart=always, RestartSec=5
  4. systemctl enable --now hermes-api
